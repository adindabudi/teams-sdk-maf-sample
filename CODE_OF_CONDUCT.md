# Code of Conduct

This community project uses the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) as its behavioral standard. This does not make the project an official Microsoft repository.

Resources:

- [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
- [Microsoft Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)

Report project conduct concerns privately through **Security > Report a vulnerability** in this GitHub repository. Prefix the report title with `Conduct:`. Do not send reports about this community project to Microsoft unless the concern involves a Microsoft-managed service or repository.
