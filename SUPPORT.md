# Support

This repository is a sample and does not provide a production support SLA.

For usage questions and reproducible bugs:

1. Check the [documentation](README.md#documentation) and [troubleshooting guide](docs/troubleshooting.md).
2. Search existing GitHub issues in this repository.
3. Open an issue with the sample version, operating system, relevant tool versions, minimal reproduction steps, and sanitized logs.

Do not include credentials, tokens, tenant identifiers, prompts, responses, or attachment content. Report suspected vulnerabilities privately according to [SECURITY.md](SECURITY.md).

Use the appropriate official support channel for Azure, Microsoft Teams, or Microsoft 365 service incidents. A repository issue cannot replace product support or tenant administration.
