# Security

Do not report security vulnerabilities through public GitHub issues.

Use **Security > Report a vulnerability** in the GitHub repository to send a private report. Include the affected version, impact, minimal reproduction steps, and any suggested mitigation. Do not include credentials, tokens, tenant data, or personal data.

The maintainers will acknowledge and triage reports according to project capacity. This sample does not provide a production support SLA.

## Supported versions

Security fixes are applied to the latest published version. Older sample versions are not maintained.
